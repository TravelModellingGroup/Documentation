# XTMF2

XTMF2 is the eXtensible Travel Modelling Framework 2. It provides the desktop environment and runtime used to compose and execute travel-model workflows from reusable modules.

New to XTMF2? Start with [Getting Started](getting-started/index.md), a guided path from the user interface and core concepts through scripting, estimation, and calibration.

Building your own extensions? Follow [Develop XTMF2 modules](developer/index.md) to create functions and actions, expose configuration, validate behavior, and install a custom module library.

For module-level details, see the [built-in module reference](modules/index.md).
