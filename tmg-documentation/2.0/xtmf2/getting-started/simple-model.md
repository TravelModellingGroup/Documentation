# Build a simple model system

Use the **Getting Started** interactive tutorial for the hands-on introduction to creating and running a model system. It guides you through adding a Start, adding a Sleep module, connecting them, adding a comment, saving, and running the model.

To open it, choose **Help** > **Interactive Tutorial…** in XTMF2, select **Getting Started**, then choose **Start Tutorial**. See [Run XTMF2 interactive tutorials](estimation-calibration.md) for the full launch instructions.

Before starting, review the [XTMF2 canvas primer](canvas-primer.md) to learn what the canvas elements represent.
