# Getting Started

This learning path introduces XTMF2 to travel modelers who are new to the framework. It starts with the desktop application and the ideas behind a model system, introduces the canvas, then points to the built-in interactive tutorials for hands-on practice.

## Learning path

1. [Introduction to XTMF2](introduction.md): understand what XTMF2 provides and how it fits with TMG modules.
2. [Set up XTMF2](setup.md): prepare the software and open the desktop application.
3. [Explore the user interface](user-interface.md): find the editor, module configuration, run controls, and results.
4. [Understand model systems](concepts.md): learn how modules, nodes, links, parameters, and execution fit together.
5. [XTMF2 canvas primer](canvas-primer.md): identify the elements you can add to and connect on the model-system canvas.
6. [Build a simple model system](simple-model.md): run the interactive Getting Started exercise.
7. [Script a log message in a loop](scripting.md): learn expression variables and operators with the Execute logging tutorial.
8. [Run XTMF2 interactive tutorials](estimation-calibration.md): launch any of the built-in guided exercises.

The interactive tutorials use separate practice projects and do not require a production travel dataset. They assume you are using the complete XTMF2 distribution with the included module libraries installed.

## Before you begin

You should be comfortable with basic travel-model terminology and with installing software on your operating system. You do not need to write C# modules to complete this path.

The interactive tutorials target the supported XTMF2 distribution. XTMF2 model-system exports contain compiled type references, so an example package should be opened with the same or a compatible XTMF2 version.

## Reference documentation

The [XTMF2 module reference](../modules/index.md) documents the built-in modules. Use it when an interactive tutorial asks you to configure a module or when you want to explore a module beyond the guided examples.
