# Run XTMF2 interactive tutorials

XTMF2 includes guided, hands-on tutorials in its desktop application. Each tutorial opens in a separate project, so you can practice without changing an existing model system. No production travel dataset is needed for the built-in exercises.

## Start a tutorial

1. Open the XTMF2 desktop application and wait for it to finish loading.
2. From the menu bar, choose **Help** > **Interactive Tutorial…**.
3. In the **Interactive Tutorials** window, select a tutorial. Tutorials are grouped by their module library.
4. Choose **Start Tutorial**. XTMF2 opens a separate project and displays the tutorial guide in the model-system editor.
5. Follow each step in the guide. Complete the requested action to enable **Next**; some steps can be advanced immediately. If available, use **Why this matters** for more context or **Skip** to prepare the example state and move on.
6. Choose **Done** when the tutorial is complete.

## Built-in tutorials

The XTMF2 library currently includes these tutorials:

- **Getting Started**: add a Start and Sleep module, connect them, add a comment, save, and run the model system.
- **Write Messages to the Run Log**: build an action sequence that writes messages to the run output.
- **Log Each Execute Iteration**: log a value from each iteration of an Execute action.
- **Reuse an Iteration Logger**: extract a workflow into a function template and use it more than once.
- **Estimate a Model Parameter**: configure and run a parameter estimation, then review and apply the result.
- **Calibrate a Model Parameter**: configure and run a calibration, then review and apply the result.

Tutorials from other module libraries may also appear when those libraries are loaded. For an overview of the elements used to assemble workflows, see the [XTMF2 canvas primer](canvas-primer.md).
